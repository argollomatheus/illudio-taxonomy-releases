# ILLÚDIO — Taxonomy of Visuals

Aplicativo local de direção visual para arquitetura e Archviz, com escopo por câmera, referências, estudos e revisão artística.

[Baixar a versão atual para Windows x64](https://github.com/argollomatheus/illudio-taxonomy-releases/releases/latest)

Baixe o instalador **ILLUDIO-Taxonomy-Setup-0.4.0.exe**. Os arquivos `.blockmap` e `latest.yml` são usados pelo atualizador e não precisam ser abertos manualmente.

## Trabalho local

Os empreendimentos ficam no computador. Exporte um arquivo `.illudio` para compartilhar escopo, direções, referências e imagens; abra o arquivo em outra máquina com o aplicativo instalado. O autosave atualiza a cópia local: exporte novamente para compartilhar mudanças.

## Atualizações

Depois de instalado, o app verifica novas versões públicas e baixa em segundo plano. Quando a atualização estiver pronta, escolha reiniciar agora ou depois. O trabalho é salvo antes de aplicar a atualização. Os projetos não são enviados ao GitHub.

Este repositório contém os instaladores e os arquivos de atualização. O desenvolvimento ocorre em um repositório privado.

## Validação desta distribuição

Instalação, associação `.illudio`, abertura inicial e segunda instância verificadas em Windows. O fluxo de atualização foi testado com simulação; a atualização real entre duas versões ainda precisa ser validada antes de distribuição ampla. Esta primeira versão ainda não possui assinatura digital.
